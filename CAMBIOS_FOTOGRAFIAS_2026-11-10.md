## Actualización en GitHub

Repositorio: https://github.com/migoreslavconstructionsac-lab/flores-web-nueva

1. Extraer el ZIP.
2. En la pestaña Code del repositorio, usar `Add file` → `Upload files`.
3. Arrastrar los archivos `index.html`, `servicios.html` y `bienes.html`, además de los **dos archivos dentro de la carpeta `assets` conservando la ruta `assets/`**. Se pueden subir primero los HTML y después entrar a la carpeta `assets` en GitHub y subir allí los dos archivos de imagen.
4. GitHub mostrará los archivos existentes para reemplazarlos. Confirmar `Commit changes`.
5. Abrir la misma URL del sitio: https://migoreslavconstructionsac-lab.github.io/flores-web-nueva/ . Usar Ctrl + F5 si el navegador muestra la copia anterior.

**No cambiar el repositorio ni el nombre de la carpeta `assets`. No es necesario crear otro sitio ni generar otro QR.**
